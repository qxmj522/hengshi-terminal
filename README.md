# 衡石资本 · 证券行情终端

浅色、克制、高级感的全球证券行情终端。支持 A 股 / 港股 / 美股实时行情、全市场搜索、自选与标签分组、双股对比、单股全屏详情，以及导出/导入本地备份。

## 在线访问

👉 **https://qxmj522.github.io/hengshi-terminal/**

## 功能

- **首页**：顶部菜单 + 居中搜索框 + 按本地时段滚动的指数条（9-15 点沪深科创 → 15-16 点恒生 → 晚间美股三大指数）
- **搜索**：按代码/名称搜索全市场（A股 5556 + 港股 2798 + 美股精选），带实时走势图、加自选（弹行业标签询问）、加对比、标签管理（每只最多 5 个）
- **自选**：全部/美股/港股/沪深筛选，23 列全字段表格（实时价、击球点、市值、PE/PB/PS、ROE、股息率、分红、回购、股本变动等），每 10 秒刷新
- **个股分组**：按标签分组，支持标签左右拖动排序、右键置顶
- **对比**：最多 2 只全屏对比
- **详情**：双击名称/代码全屏查看走势图 + 基本信息
- **数据**：仅存浏览器本地（localStorage），无账号；支持导出/导入备份迁移

## 数据源

- 实时行情：腾讯行情源（`qt.gtimg.cn`），前端直连，A股/港股/美股/指数全覆盖
- 搜索：内置全量本地股票清单（`js/stocklist.js`）

## 本地运行

纯静态部署（GitHub Pages 等）即可运行，无需后端。若需要双源行情/管理员等后端能力，可本地运行：

```bash
node server.js
# 访问 http://127.0.0.1:8899
```

## 项目文件结构

| 文件 | 作用 |
|---|---|
| `index.html` | 页面主入口：顶部菜单、居中搜索框、按时段滚动的指数条、各模块容器、单股全屏详情与对比浮层 |
| `css/style.css` | 全局样式：浅色克制高级感设计、版心 1700px、红涨绿跌、表格/卡片/弹窗/动画 |
| `js/stocklist.js` | 全市场股票清单（A股 5556 + 港股 2798 + 美股精选），供搜索本地毫秒级匹配，离线也能搜 |
| `js/data.js` | 内置基线数据：指数与代表性个股的静态快照、货币与市场常量 |
| `js/engine.js` | 行情引擎与数据层：实时行情（腾讯直连 + 本地行情桥降级）、localStorage 存储、股票代码规范化、字段计算与格式化 |
| `js/charts.js` | 图表绘制：分时 / 日K / 周K / 月K、迷你走势图（Canvas） |
| `js/app.js` | 主应用逻辑：路由、搜索、自选、个股分组、对比、单股详情、个人账户、导出/导入 |
| `server.js` | （可选）本地服务器：行情桥（双源）+ 管理员鉴权；纯静态部署无需 |
| `.nojekyll` | 告知 GitHub Pages 跳过 Jekyll 处理，原样托管静态文件 |
| `.gitignore` | Git 忽略规则（排除 `admin.json` 密码、本地数据、Python 脚本等） |

## 技术栈

纯 HTML / CSS / JavaScript，零依赖、零构建。
